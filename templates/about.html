About Zwidth Paste

What is Zwidth Paste?

Zwidth Paste is a simple, fast markdown-based text sharing platform. Share text content instantly with custom or random URLs, protect content with edit codes, and preview in real-time.

Key Features

  • Markdown Support: Write content using markdown for rich formatting
  • Custom URLs: Choose your own URL or use auto-generated ones
  • Edit Codes: Protect your entries with secure edit codes
  • Modify Codes: Share limited access codes for content-only editing
  • No Registration Required: Create entries without signing up
  • Spam Protection: Hashcash proof-of-work prevents abuse

URL Rules

  • Length: 2-100 characters
  • Allowed characters: lowercase letters, numbers, underscores, and hyphens
  • URLs are case-insensitive (stored as lowercase)

Content Limits

  • Text content: 200,000 characters maximum
  • Edit code: 1-100 characters
  • Modify code: 1-100 characters

Edit Code vs Modify Code

Action Edit Code Modify Code
Edit content ✅ Yes ✅ Yes
Change URL ✅ Yes ❌ No
Change codes ✅ Yes ❌ No
Delete entry ✅ Yes ❌ No

Spam Protection

Zwidth Paste uses hashcash proof-of-work to prevent spam. When creating entries, registering, or logging in, your browser computes a small cryptographic puzzle. This takes a few seconds but prevents automated abuse.
